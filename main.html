BYOK 模型設定 (Bring Your Own Key)

文字模型用於回答、摘要、深度分析、心智圖架構與圖像/影片腳本規劃。
可點擊右上角自動拉取該供應商可用模型
💡 若直接連線出現「Load failed」，通常是官方端點阻擋了瀏覽器直接跨域 (CORS)。
瀏覽器直連與「Load failed / CORS」徹底解決方案：
  • NVIDIA Build (NIM)：端點已內置為 https://integrate.api.nvidia.com/v1，支援 Llama-3.3-70B、DeepSeek-R1/V3、Nemotron 等！
  • DeepInfra：端點已內置為 https://api.deepinfra.com/v1/openai，性價比極高，原生支援標準 OpenAI 相容格式。
  • 一鍵拉取模型清單：填入 API Key 後，點選右上角「線上拉取模型清單」，系統將自動從供應商端點檢索所有可用模型名稱並供點選。
  • 瀏覽器 CORS 提示：若在純前端直連官方遇到 Load failed，可使用上方「CORS 代理」一鍵加上轉發代理。
圖片模型用於產生插圖、簡報視覺素材與影片場景畫面。
TTS 模型用於將文字模型生成的摘要、演講備忘錄與影片腳本轉化為語音音訊。
轉錄模型 (STT) 用於將使用者上傳的音頻或影片來源轉錄為文字以建立檢索索引。
